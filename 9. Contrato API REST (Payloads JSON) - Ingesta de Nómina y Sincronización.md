Contrato API REST (Payloads JSON) - Ingesta de Nómina Ministerial y Sincronización Offline

Este documento especifica los contratos de API REST, cabeceras de seguridad y estructuras JSON para la integración entre los sistemas de Gestión Humana ministerial (SAP, SIGECOF, nóminas públicas), el Portal Web de Gobernanza y las aplicaciones móviles de despacho de víveres y combos proteicos en almacenes.

--------------------------------------------------------------------------------
1. Endpoints de Ingesta de Nómina y Gestión Humana (SSOT)

1.1 Webhook de Novedades en Tiempo Real
- Endpoint: POST /api/v1/payroll/webhook
- Descripción: Recibe actualizaciones individuales de funcionarios y jubilados en tiempo real desde el sistema central de RRHH.
- Headers:
  - Content-Type: application/json
  - X-Payroll-Signature: sha256={hmac_signature}
- Payload JSON:
{
  "event_id": "evt_9876543210_20261018",
  "event_type": "employee.updated",
  "timestamp": "2026-10-18T08:30:00Z",
  "data": {
    "worker_id": "a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11",
    "document_id": "V-18456123",

1.3 Kill-Switch de Bajas Inmediatas
- Endpoint: POST /api/v1/payroll/employees/{worker_id}/terminate
- Descripción: Revoca de forma inmediata en cascada todas las llaves Passkey, tarjetas NFC y asignaciones de jornadas no retiradas ante egreso o desincorporación de nómina.
- Payload JSON:
{
  "worker_id": "a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11",
  "termination_date": "2026-10-18T10:00:00Z",
  "reason": "renuncia_cargo",
  "authorized_by": "directora_gestion_humana_rrhh"
}
