Contrato API REST (Payloads JSON) - Ingesta de Nómina Ministerial y Sincronización Offline
Versión: 2.0 (Ingesta CSV, Respaldo Preventivo JSON, Asistente B2G y Métricas de Tonelaje)

Este documento especifica los contratos de API REST, cabeceras de seguridad y estructuras JSON para la integración entre los sistemas de Gestión Humana ministerial (SAP, SIGECOF, nóminas públicas), el Portal Web de Gobernanza y las aplicaciones móviles de despacho de víveres y combos proteicos en almacenes.

--------------------------------------------------------------------------------
1. Endpoints de Ingesta de Nómina y Gestión Humana (SSOT)

1.1 Descarga de Plantilla Oficial de Nómina CSV
- Endpoint: GET /api/v1/payroll/sample-payroll.csv
- Descripción: Entrega un archivo CSV con cabeceras predefinidas y registros de ejemplo para la carga del padrón.
- Estructura CSV:
```csv
document_id,full_name,email,department,worker_type,has_smartphone
V-18456123,Carlos Eduardo Mendoza,carlos.mendoza@ministerio.gob.ve,Dirección General de Tecnología,activo,true
V-06894321,Hilda Teresa Domínguez,,Atención al Ciudadano,jubilado,false
```

1.2 Ingesta Masiva / Carga Batch (CSV o Arreglo JSON)
- Endpoint: POST /api/v1/payroll/batch-import
- Descripción: Procesa cargas masivas del padrón ministerial activo y jubilado para una jornada programada. Soporta tanto payload JSON estructurado como texto plano CSV.
- Payload JSON:
```json
{
  "batch_id": "batch_20261018_jornada_viveres_proteina",
  "source": "csv_import_rrhh",
  "total_records": 2,
  "workers": [
    {
      "document_id": "V-18456123",
      "full_name": "Carlos Eduardo Mendoza",
      "email": "carlos.mendoza@ministerio.gob.ve",
      "department_name": "Tecnología y Comunicaciones",
      "worker_type": "activo",
      "status": "active",
      "has_smartphone": true,
      "contingency_reason": null
    },
    {
      "document_id": "V-06894321",
      "full_name": "Hilda Teresa Domínguez",
      "email": null,
      "department_name": "Jubilados Institucionales",
      "worker_type": "jubilado",
      "status": "active",
      "has_smartphone": false,
      "contingency_reason": "adulto_mayor_sin_smartphone"
    }
  ]
}
```
- Respuesta JSON:
```json
{
  "status": "success",
  "imported_count": 2,
  "updated_count": 0,
  "duplicates_omitted": 0,
  "timestamp": "2026-10-18T08:35:00Z"
}
```

1.3 Webhook de Novedades en Tiempo Real
- Endpoint: POST /api/v1/payroll/webhook
- Descripción: Recibe actualizaciones individuales de funcionarios y jubilados en tiempo real desde el sistema central de RRHH.
- Headers:
  - Content-Type: application/json
  - X-Payroll-Signature: sha256={hmac_signature}
- Payload JSON:
```json
{
  "event_id": "evt_9876543210_20261018",
  "event_type": "employee.updated",
  "timestamp": "2026-10-18T08:30:00Z",
  "data": {
    "worker_id": "a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11",
    "document_id": "V-18456123",
    "full_name": "Carlos Eduardo Mendoza",

    "status": "active",
    "has_smartphone": true,

```

1.4 Kill-Switch de Bajas Inmediatas
- Endpoint: POST /api/v1/payroll/employees/{worker_id}/terminate
- Descripción: Revoca de forma inmediata en cascada todas las llaves Passkey, tarjetas NFC y asignaciones de jornadas no retiradas ante egreso o desincorporación de nómina.

3. Endpoints de Gobernanza, Respaldo Preventivo y Puesta a Cero

3.1 Descarga de Snapshot Preventivo JSON
- Endpoint: GET /api/v1/admin/export-backup
- Descripción: Exporta un volcado completo de la base de datos en formato JSON para custodia obligatoria antes de reseteos.
- Respuesta JSON (ejemplo truncado):
```json
{
  "metadata": {
    "system": "Plataforma Combos Beneficios B2G",
    "export_timestamp": "2026-10-18T18:00:00Z",
    "entity_name": "MIPPCI",
    "version": "2.0"
  },
  "tables": {
    "tenant_settings": [...],
    "departments": [...],
    "workers": [...],
    "combos": [...],
    "campaigns": [...],
    "deliveries": [...]
  }
}
```

3.2 Puesta a Cero de Base de Datos (Factory Reset)
- Endpoint: POST /api/v1/admin/factory-reset
- Payload JSON:
```json
{
  "confirm_reset": true,
  "admin_password": "..."
}
```
- Respuesta JSON:
```json
{
  "success": true,
  "message": "Base de datos restablecida a cero con éxito para nueva gestión."
}
```
